一、场景核心理解与定义

一句话描述这个场景

商家打造一个没有真实品牌内涵的"空壳品牌"，通过高端包装和高价定价，让消费者误以为买到了大牌或洋牌，为此支付远超商品本身价值的溢价。

场景正式命名

将"假大牌"与"假洋牌"合并，统一命名为：

虚假品牌塑造（Fake Brand Fabrication，简称 FBF） 涵盖仿国内高端品牌（假大牌）和仿国际品牌（假洋牌）两类子场景。

什么样的品牌是"空壳品牌"

真实品牌与空壳品牌的根本区别，在于是否有真实的品牌价值基础：

维度真实品牌（不干预）空壳品牌（本场景治理对象）
产品线 有自有研发、自主配方或工艺，能解释差异化 纯 OEM / 白牌贴标，无自有产品线，换个牌子就是另一家
品牌历史 品牌故事可核实，有积累 品牌注册时间极短，历史故事虚构或无法核实
价格支撑 高价有依据：专利成分、稀缺原料、工艺认证等 高价无依据：靠包装和名字营造高端感，无实质支撑
品牌来源 国内品牌如实标注，进口品牌有真实资质 用外文名、欧式包装、"源自德国/法国"等制造进口联想

二、场景三要素：缺一不可

💰
价格虚高溢价
定价明显超出同类商品合理区间，溢价来自虚假品牌感，而非真实产品差异化
核心铆钉
🫙
品牌空壳化
无真实产品线、无自有研发、无可核实品牌背书，是一个没有实质内涵的包装外壳
核心信号
🎭
外观误导消费者
通过名称、包装、故事制造"大牌感"或"洋牌感"，让消费者以为在买有价值的品牌
必要条件
要素缺失时如何处理？ • 缺少"价格虚高"→ 消费者未被多收钱，本场景治理优先级极低，观察记录即可
• 缺少"品牌空壳化"→ 可能是真实新锐品牌的高端定位，不应干预
• 缺少"外观误导"→ 可能只是贵，不构成品牌欺骗，看具体情况

价格溢价的量化基准

溢价倍数（售价 ÷ 同类均价）含义治理级别参考
＜ 1.5x无明显溢价本场景不触发
1.5x ～ 2x轻度溢价C级观察
2x ～ 5x中高度溢价B / A级
≥ 5x严重溢价S级

同类均价 = 同品类、同规格、同功能商品在京东平台的销量加权均价，每月更新。

三、典型案例判定

案例 1 本田制药 — 国内品牌，价格不高
品牌情况国内注册品牌，名称借用"本田"，与日本本田汽车无任何关联
产品情况OEM代工产品
定价同类保健品均价80元，该品牌定价 85元（无明显溢价）
✅ 判定：不触发虚假品牌塑造 价格无溢价，消费者没有因品牌误导而多付钱，本场景三要素中"价格虚高"不成立，治理优先级极低。

但需注意：若"本田"与日本本田汽车构成商标混淆，可转知识产权/商标侵权场景处理，与本场景无关。
案例 2 本田制药 — 同品牌，但定价很高
品牌情况同上，国内品牌借用"本田"名称
包装使用日文、日系设计风格，品牌详情页暗示"日本技术"
定价同类保健品均价80元，该品牌定价 480元（6倍溢价）
产品线无自有研发，纯OEM代工
🔴 判定：触发虚假品牌塑造，S级 三要素全部成立：① 6倍溢价（价格虚高）② 纯OEM无产品线（品牌空壳化）③ 名称+日系包装制造进口联想（外观误导）。

治理逻辑：消费者为"本田=日本品牌"的错误认知多花了400元，这是本场景要解决的核心伤害。
案例1 vs 案例2 的关键启示 同一个品牌名称"本田制药"，价格不同，结论完全不同。
这证明了：不是品牌名称本身决定是否违规，而是价格溢价+品牌空壳+外观误导三者共同决定。
价格是判断消费者是否受到实质损害的核心铆钉。
案例 3 某品牌宣称"德国品质"
品牌情况国内品牌，在国内生产，无德国工厂或德国机构授权
宣传语"德国品质认证"、"源自德国工艺"

这是一个跨越两个场景的典型灰色地带，判断取决于具体表述和价格：

具体表述定价判定场景
"德国制造" / "德国原装进口"，但实际国内产 任意价格 虚假宣传（具体可核实的产地假陈述）
"获得德国TÜV认证"，但实际无认证 任意价格 虚假宣传（可核实的认证假陈述）
"德国品质"（模糊表述，无具体假陈述）+ 高溢价 + 外文品牌名 + 欧式包装 ≥ 2x均价 虚假品牌塑造（整体氛围误导+价格溢价）
"德国品质"（模糊表述）+ 价格正常 ≤ 1.5x均价 低优先级观察（无实质消费者损害）
💡 判定原则 有具体假陈述 → 先走虚假宣传核查。无具体假话但靠整体氛围+高溢价误导 → 走虚假品牌塑造。两者同时存在 → 双重标记，取较重处置。
案例 4（对照） 某国内新锐美妆品牌，定价高但有真实支撑
品牌情况国内品牌，成立3年，有真实研发团队、专利成分、媒体报道
产品线有自有配方研发，部分成分申请了专利
定价面霜580元（高于均价约2.5倍），但产品差异化明确
✅ 判定：不触发，属于真实品牌溢价 "品牌空壳化"不成立：有真实产品线和研发背书，价格溢价有合理依据。
平台不干预真实的品牌溢价定价权。

四、与虚假宣传的本质区别

🔵 虚假宣传（现有场景）

  • 针对商品属性的虚假陈述
  • 有具体可逐一核实的假话
  • 成分、功效、认证、产地事实不符
  • 找到那条假话就命中
  • 价格高低不是判定条件
  • 核心问题：
    买到的东西和描述不一样

🔴 虚假品牌塑造（新场景）

  • 针对品牌身份的整体性虚假营造
  • 不一定有单条假话，靠整体氛围误导
  • 品牌空壳化 + 外观包装误导
  • 综合多维信号打分判断
  • 价格虚高是核心必要条件
  • 核心问题：
    以为买的是大牌，多付了冤枉钱

一句话判断路径

先问：有没有具体的、可核实的虚假事实陈述？（成分/功效/产地/认证）
→ 有 → 虚假宣传，同时检查是否叠加品牌溢价
→ 没有，但整体形象+高价让消费者误认为是大牌 → 虚假品牌塑造

两场景判定矩阵

情形虚假宣传虚假品牌塑造处置原则
仅有成分/功效/认证不实✅❌走虚假宣传
仅有品牌形象虚假+价格溢价❌✅走本场景
两者同时存在✅✅双重标记，取较重处置叠加执行
"德国品质"+具体认证造假✅视溢价虚假宣传优先，叠加溢价检查
"德国品质"+无具体假话+高溢价❌✅走本场景
涉及商标侵权视情况✅知产场景优先，叠加本场景
本田制药，低价无溢价❌❌转知产场景（若商标混淆）

五、识别规则与评分模型

五维加权评分模型

维度权重说明
💰 价格溢价30%（最高）核心铆钉，无溢价则整体评分大幅降低
🫙 品牌实体性25%（新增）有无真实产品线、自有研发、可核实品牌背书
🏷️ 品牌名称/视觉20%与知名品牌的相似度、外文名真实性、包装仿冒程度
📖 品牌故事真实性15%来源地、历史、荣誉的可核实程度
💬 用户反馈10%差评/申诉中品牌误导相关投诉量

💰 价格溢价维度（权重30%）

评分判定标准
80分 高风险售价 ≥ 同类均价 × 5倍，且无可信差异化依据
50分 中风险售价介于同类均价 × 2 ～ 5倍
20分 低风险售价介于同类均价 × 1.5 ～ 2倍
0分售价 < 同类均价 × 1.5倍（不触发）

🫙 品牌实体性维度（权重25%，新增）

评分判定标准
80分 高风险无任何自有产品线，全部 OEM / 白牌贴标，且无自有专利/配方
80分 高风险品牌注册时间 < 1年，且无历史背书记录
50分 中风险有少量自有产品，但核心 SKU 均为代工，无可核实研发投入
20分 低风险有一定自有产品线，但品牌故事存在部分夸大
0分有充分自有研发、专利、品牌历史可核实

🏷️ 品牌名称/视觉维度（权重20%）

评分判定标准
80分 高风险与知名品牌名称字形/发音相似度 ≥ 70%
80分 高风险主图/包装与知名品牌视觉相似度 ≥ 60%（AI图像比对）
80分 高风险标注"Made in France/Germany/Japan"等但实际国内产
50分 中风险纯外文品牌名，无任何可核实的海外注册记录
20分 低风险整体调性借鉴国际大牌，但无直接仿冒

📖 品牌故事维度（权重15%）

评分判定标准
80分 高风险声称"创立于欧洲/日本XX年"但无任何可核实依据
80分 高风险宣称获得国际品牌授权/合作，无法提供授权文件
50分 中风险模糊表述"源自欧洲工艺传承"等，无具体可查信息

💬 用户反馈维度（权重10%）

评分判定标准
80分 高风险差评含"以为是大牌/洋牌"、"价格欺骗"等语义 ≥ 15条/月
80分 高风险因品牌误导退货申诉成立率 ≥ 30%
50分 中风险问答区频繁出现"这是什么牌子"、"是进口的吗"等疑问

综合评分分级

综合评分风险等级标签
≥ 75分严重🔴 S级 — 虚假品牌塑造
55 ～ 74分较重🟠 A级 — 疑似品牌误导
35 ～ 54分中等🟡 B级 — 品牌包装待规范
< 35分轻微/不触发🟢 C级观察 / 不触发

六、风险分层处置方案

治理总原则：不下架，让价格回归真实，保护消费者不被虚假溢价欺骗 核心逻辑：打压自然流量 + 允许付费广告 = 逼迫商家以真实价格竞争市场。
商家若仍想获得流量，只能通过付费投放，且需通过品牌真实性审核。自然流量"免费红利"消失后，高溢价难以为继，价格自然回归。
S 级
严重 · 即时干预
综合评分 ≥ 75分
措施类型具体内容
自然流量搜索流量 + 算法推荐流量全部清零
付费广告允许投放，广告素材须通过品牌真实性专项审核后上线
页面干预商品详情页顶部展示醒目标识："该商品存在品牌误导风险，建议对比同类商品价格后购买"
下单拦截消费者下单前弹窗："该商品价格高于同类均价 X 倍，请理性消费"
商家通知发送 S 级违规通知，要求 7 天内完成整改
消费者保护开放"品牌误导"专项维权通道，平台协助退款协调
未整改升级7 天未整改 → 商家账号降级，全店商品流量受连带影响
知产交叉涉嫌商标侵权 → 同步转知识产权场景，可触发下架
复查周期7 天后强制重新评分
A 级
较重 · 中度限制
综合评分 55 ～ 74分
措施类型具体内容
自然流量搜索排名下降 50%
推荐流量猜你喜欢、首页推荐等算法场景全部停止
付费广告允许投放，需额外提交品牌真实性证明材料
强制披露商品页展示："本品牌为国内自主品牌，与国际知名品牌无关联"（如适用）
品牌标签商品列表页品牌名旁增加 自有品牌 标签
下单提示下单前展示同类商品均价对比信息
申诉窗口给予 15 天申诉期，可提交完整品牌资质材料
复查周期15 天后重新评分
B 级
中等 · 轻度限制
综合评分 35 ～ 54分
措施类型具体内容
自然流量搜索排名下降 20%～30%
推荐流量推荐场景流量减少 30%
付费广告正常投放，广告素材需标注真实品牌来源地
价格提示商品页展示"同类商品参考价：约 XX 元"
商家引导引导商家补充品牌商标证、产地证明、研发背书等资质
申诉窗口7 天申诉期
复查周期30 天后重新评分
C 级
轻微 · 观察引导
综合评分 < 35分
措施类型具体内容
流量影响无
商家提醒发送"品牌信息规范建议"，提示存在的风险信号
信息引导引导商家主动补全品牌资质信息
复查周期30 天内持续监测，无改善升级至 B 级

整改验收标准（S / A 级）

整改项验收标准
价格调整售价调至同类均价 ≤ 3倍，或提交充分的产品差异化证明（专利/认证/原料说明）
品牌实体性提供自有产品线证明（自有配方/专利/研发资质）或真实 OEM 合同+产品差异化说明
品牌名称/包装去除与知名品牌相似的仿冒元素，或提供合法授权文件
虚假标注去除虚假产地标注、虚假认证标志、虚假奖项
信息透明主动展示品牌真实信息（国内品牌/注册时间/注册地）

八、场景协同机制

双向移交规则 • 本场景核查中发现具体虚假陈述（成分/认证/产地）→ 自动推送虚假宣传团队
• 虚假宣传核查中发现品牌整体存在溢价+仿冒 → 同步触发本场景评分
• 两场景均命中 → 各自独立标记，处置措施取较重叠加执行
• 本田制药类品牌（低价+商标混淆）→ 转知识产权场景，与本场景无关
