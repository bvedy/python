# 假货治理 · Agent 协同工作区

本仓库是假货治理部门与 AI Agent 协作的**持久化工作区**。

## 为什么这样能让 Agent 更准确？

AI 会话是临时的，关掉就忘。但**仓库是持久的**。
把你的工作标准沉淀进仓库，每次新会话让 Agent 先读一遍，它就自动按你的体系工作——
不用每次重新解释，而且标准随用随改、越用越准。

```
你的标准（写进仓库）
      ↓ 每次会话 Agent 先读
Agent 按统一口径执行识别 / 分析 / 决策 / 验证
      ↓ 产出
标准化报告（周报 / 应急判断 / 闭环验证）
      ↓ 效果反馈
回头校准标准 → 仓库更新 → 下次更准
```

## 文件说明

| 文件 | 作用 |
|------|------|
| `调校体系设计.md` | **核心**：案例库+规则库+调试闭环，让 Agent 判断越用越准 |
| `假货治理工作框架体系.md` | 背景框架：四层架构 + 四大标准（为调校体系提供标准底座） |

> 两者关系：**框架体系**是静态的"标准底座"（数据怎么定义、风险怎么分级）；
> **调校体系**是动态的"判断引擎"（靠案例和规则反复纠偏，把准确率磨上去）。
> 框架定"该看什么"，调校定"判得准不准"。

## 怎么用（三步）

1. **立标准**：打开 `假货治理工作框架体系.md`，补全所有标【待填写】【待校准】的项。
2. **跑场景**：给 Agent 一个场景标签（如"周报"）+ 数据文件，它自动套标准产出。
3. **持续迭代**：标准有变就改这个文件，git 自动留痕、可回溯。

## 输入给 Agent 的标准格式

```
场景：周报 / 快速判断 / 闭环验证 / 月报
数据：附件 xlsx，或粘贴关键指标
参数：周期、对标基准、重点维度、面向对象
```
